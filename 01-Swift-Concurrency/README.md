# 01 - Swift Concurrency Demo

## Overview
Demonstrates production-grade Swift Concurrency patterns in SwiftUI:
- Parallel multi-image/news feed fetching with concurrency limits using `TaskGroup`
- Thread-safe caching with a dedicated `actor` (`ImageCache`)
- Live event streaming using `AsyncStream`
- Cooperative task cancellation when navigating away or refreshing views
- 100% clean Swift 6 concurrency mode (no data races or warnings)
